# Application Description — Lavcom Performances

## 1. Business Model

### Value Proposition
Lavcom Performances is a French B2B SaaS platform for self-service laundromat operators. It transforms raw transaction data (CSV exports from machine controllers WiLine, LM Control, etc.) into actionable analytics, profitability insights, marketing recommendations, and bank-grade financial business plans. It also serves prospective operators with a free pre-investment simulator.

### Revenue Streams
| Stream | Audience | Pricing | Mechanism |
|---|---|---|---|
| **SaaS subscription** (`Subscribe` / `subscriptions`) | Active operators | Monthly/annual recurring | Stripe Checkout + Customer Portal |
| **Simulator one-shot packs** (`SubscribeSimulator`) | Prospects in financing/location stage | Pack Essentiel / Pack Projet / Pack Comparateur / Pack Premium (one-time) | Stripe Checkout, time-boxed access |
| **Add-ons** (`create-addon-checkout`) | Existing simulator users | +30 days extension / +1 project | Stripe Checkout one-shot |
| **Beta program** | Early adopters | Free during beta, conversion at end | `beta_company_overrides` flag |
| **14-day free trial** | New SaaS signups | Free, no card required | Trial reminder cron + paywall |

### Target Users
- **Operators** (multi-site laundromat owners) — main SaaS audience.
- **Prospects / project carriers** — use the free simulator (`/simulateur`) before investing.
- **Lavcom internal team (super-admins)** — platform monitoring, compliance, sales analytics.
- **Bank advisors / experts** — receive PDF business plans generated by operators.

### Monetization Flow
1. Prospect lands on `/simulateur` → completes qualification + simulation → email captured (`simulator_leads`).
2. Segmented redirect (A/B/C/D) routes them to the right pack on `/subscribe-simulator`.
3. Active operators sign up → 14-day trial → paywall blocks features after expiry → `Subscribe` page.
4. Stripe webhook (`stripe-webhook`) reconciles `subscriptions` and `purchases` rows.
5. `stripe-reconcile-cron` repairs drift nightly; `trial-reminder` nudges expiring trials.

- **Hosting**: Lovable hosting (SPA fallback built-in), preview at `id-preview--*.lovable.app`, published at `lavcom-performanes.lovable.app`.

## 3. Domain Isolation Strategy

The system runs **two completely separated identity domains**:

| Domain | Hostname | Auth | DB Tables | Purpose |
|---|---|---|---|---|
| **Public marketing** | `lavcom.fr` (WordPress) | None | None | SEO, blog, lead gen |
| **SaaS platform** | `app.lavcom.fr` / `lavcom-performanes.lovable.app` | Supabase Auth | All `public.*` tables | Authenticated app + admin |

**Rules** (enforced everywhere):
- Public WordPress and SaaS share **no auth, no cookies, no session**.
- Every authenticated query checks `auth.uid()` AND `site_id` ownership via `owns_site()` / `owns_operation_site()` SQL functions.
- Soft-delete only — `deleted_at IS NULL` filters protect history (`laundromat-close-reactivate-flow`).
- Roles live in `public.platform_roles` (NOT in `profiles`) — checked via `has_platform_role()` security-definer function to prevent recursive RLS.
- Demo entities are flagged `demo_mode=true`, expire after 30 minutes, isolated from real org data.
- Super-admins have a context switch (`lavcom_app_context` localStorage) to access `/admin` routes; impersonation sessions max 30min, 10/day, blocked from `/admin`.

### Key Relationships
```

                        ├─► organizations (1-N as owner)
                        ├─► sites (1-N as user_id)
                        └─► platform_roles (1-N)

organizations ──┬─► sites (1-N)
                ├─► team_invitations (1-N)
                └─► beta_company_overrides (1-1)

sites ──┬─► operations (1-N) ─► import_batches
        ├─► analytics_daily / analytics_kpis (1-N)
        ├─► site_access (N-N with users)
        ├─► site_costs / kpi_objectives (1-N)
        └─► export_jobs / diagnostics_bundles (1-N)

fin_workspaces ─► fin_projects ─► fin_scenarios ─► fin_line_items
                                  └► fin_hypotheses ─► fin_hypothesis_snapshots
                                  └► fin_forecasts
                                  └► fin_exports

kb_sources ─► kb_knowledge ─┬─► kb_knowledge_versions
                            ├─► kb_faq
                            └─► kb_rules
```

### Security Model (Multi-Tenant Isolation)
- **RLS enabled on every public table.** Bypass only via `SECURITY DEFINER` helper functions.
- **Helper functions** (security-definer, fixed search_path):
  - `owns_site(site_id)` — user owns or has `site_access`.
  - `owns_operation_site(operation_id)` — operation belongs to owned site.
  - `has_platform_role(role)` — checks `platform_roles` without recursion.
  - `is_super_admin()`, `rpc_has_paywall_bypass()`.
- **Storage policies** mirror the same logic (avatars, exports, backups buckets).
- **Edge functions** verify JWTs explicitly when handling user data; guest-accessible functions (`create-simulator-checkout`, `create-simulator-lead`) include CORS headers and validate Stripe-side.
- **Kill-switches** (`platform_feature_flags`) let super-admins instantly disable imports/AI/Stripe without redeploy.
- **CSV exports** are sanitized against formula injection (cells starting with `=`, `+`, `-`, `@` get prefixed `'`).

## 9. Key Features Summary
- **Multi-site dashboard** with KPIs, 11 chart types, revenue heatmap, expert mode toggle, period comparison.
- **CSV import pipeline** with adapter registry (WiLine, LM Control), dedupe, parser self-tests cron, 10 MB / 200k row guardrails.
- **Profitability suite** — net profit, margin, costs breakdown, linear regression forecasts.
- **Financial projections / Business Plan** — hypotheses, scenarios, 3y forecast, bank-grade PDF (TTC↔HT, #2F75B5 headers).
- **Free simulator** — 4-step qualification + ICI score (Ambition vs Capital) + segmented A/B/C/D redirect + email capture.
- **Recommendations engine** — i18n marketing rules + AI-augmented insights, PDF export.
- **Multi-tenant** with `owns_site()` everywhere, soft-delete, demo isolation, paywall bypass allowlist.
- **Security center** — deterministic 0-100 score (base 40, MFA +30, backup +20), MFA TOTP, recovery codes, trusted devices, login risk detection (country/device 90-day).
- **Compliance & DR** — monthly compliance reports, audit log archives, DR drills with ScreenshotOne + SHA256 verification, kill-switches.
